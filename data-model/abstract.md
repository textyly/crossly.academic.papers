# Matrix-based, stitch-agnostic data model for digital embroidery pattern design

Abstract. Digital embroidery tools have traditionally relied on data models that define stitches by type, closely mimicking the human perception of distinct stitch forms. While intuitive, this approach limits flexibility - particularly in software-driven design, editing, visualization and data manipulation. This paper introduces a matrix-based, stitch-agnostic data model that represents embroidery patterns as sequences of dot indexes on a matrix. By defining needle paths through matrix indexes rather than categorizing stitch types, the model offers a more precise, extensible, platform-independent representation of embroidery patterns. Unlike type-based models, this approach allows any stitch form - existing or newly invented - to be described without requiring modifications to the model or supporting software. Furthermore, by exposing low-level stitching paths as structured spatial data, the model enables both static analysis (e.g., technique validation, thread estimation) and dynamic analysis, including AI-driven tasks such as pattern recognition, error detection, and automated design generation.
