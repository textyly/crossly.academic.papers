# A dot-based, dual-view user interface for realistic embroidery simulation

Abstract. Traditional digital embroidery tools provide a grid-based user interface that allows users to fill squares with predefined stitches and colors, limiting the dynamic nature of the real embroidery process. This paper introduces a dot-based, dual-view user interface for embroidery simulation, enabling users to create stitches by connecting pairs of dots on a grid—simulating the actual movement of a needle through fabric. The dual-view canvas reveals both the front and back sides of the embroidery simultaneously, offering real time insight into how stitched patterns evolve on both surfaces. In contrast to the physical process, where the embroiderer can view only one side at a time, the proposed user interface enables continuous awareness of both sides—supporting learning, precision, and creative exploration in a uniquely digital environment.
